## 1. 产品结构(页面与流程)
```
启动页(健康游戏忠告) → 首次:隐私政策同意弹窗 → 主页
主页 ─┬─ 开始(第N关) → 关卡开始弹窗(开局道具、扣1体力) → 游戏页 → 胜利页 / 失败页
      ├─ 关卡地图(章节路线,已通关星级、宝箱)
      ├─ 商店(金币包、道具包、新手礼包、去广告、看广告领金币)
      ├─ 每日签到(7日)
      ├─ 星星宝箱(每30星)
      └─ 设置(音乐、音效、震动、隐私政策、用户协议、联系我们、恢复购买、版本)
通用弹窗:体力不足、道具不足(买/看广告)、获得奖励、广告加载失败、确认购买
```

## 2. 经济系统(初始数值,后续按数据调)
**金币来源**
| 来源 | 数量 |
|---|---|
| 新玩家初始 | 200 |
| 通关 | 10 + 每颗星 10(最多 40);困难关×1.5,超难关×2 |
| 通关后看广告 | 本关金币×2 |
| 每日签到 | 第1–7天:50 / 80 / 100 / 道具×1 / 150 / 200 / 宝箱(300+各道具×1) |
| 星星宝箱 | 每累计 30 星:100 金币 + 随机道具×1 |
| 商店看广告 | 每次 50,每天 5 次 |
| 内购金币包 | 见第 4 节 |

**金币消耗**
| 用途 | 价格 |
|---|---|
| 撤回 / 移出 / 洗牌 各补 1 个 | 60 / 90 / 70 |
| 道具组合包(三种各3个) | 450 |
| 开局道具“多一格托盘”(本关托盘8格) | 120 |
| 开局道具“磁铁”(开局自动凑出一组三连) | 100 |
| 失败复活(移出3块继续,每关一次) | 150(或看广告) |
| 补满体力(5点) | 200 |

**体力**:上限 5,失败扣 1(胜利不扣),每 30 分钟恢复 1;看广告 +1(每天最多 5 次);第 1–5 关不扣体力(新手保护)。

**道具库存**:每关开局赠送的 1 次免费道具改为“库存”:新玩家各 3 个;用完后弹“道具不足”弹窗(花金币买或看广告得 1 个)。

## 3. 广告位(激励视频为主,插屏克制)
| 位置 | 类型 | 规则 |
|---|---|---|
| 胜利页“双倍金币” | 激励 | 每关一次 |
| 失败页“看广告复活” | 激励 | 每关一次 |
| 道具不足“看广告得1个” | 激励 | 每种道具每天 3 次 |
| 体力不足“看广告得1体力” | 激励 | 每天 5 次 |
| 商店“免费金币” | 激励 | 每天 5 次 |
| 每日签到“双倍领取” | 激励 | 每天 1 次 |
| 关卡之间插屏 | 插屏 | 第 8 关后;每 3 关最多 1 次;两次间隔 ≥90 秒;失败后不弹;购买“去广告”后关闭 |
不放横幅广告(破坏画面)。所有广告走统一接口 `AdService`(先做模拟实现:2 秒后回调成功,可配置失败用于测试)。

## 6. 代码模块
| 模块 | 内容 |
|---|---|
| `scripts/meta/profile.gd` | 存档:金币、体力、道具库存、星级、签到、宝箱、购买记录、设置 |
| `scripts/meta/economy.gd` | 价格与奖励表(读 `data/economy.json`) |

| `scripts/services/ad_service.gd` | 广告接口 + 模拟实现 + 频控 |
| `scripts/services/purchase_service.gd` | 内购接口 + 模拟实现 |
| `scripts/ui/router.gd` | 页面切换与弹窗栈 |
| `scenes/…` 各页面 | 主页、地图、商店、设置、签到、启动页及各弹窗 |
规则层(GameState)不依赖任何页面;页面只读存档、发起动作。
