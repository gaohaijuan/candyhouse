# 甜点三连 · Sweet Triple — 玩法设计(总指挥)

## 定位
热门“三连消除 + 叠层”玩法(同类:Tile Master、3 Tiles、羊了个羊),竖屏休闲手游。题材:明亮的甜品烘焙屋,方块上是甜点图案。目标:做出一个可玩的 demo,验证“Codex 作图 + 总指挥写代码”的流程。

## 核心规则
1. 棋盘上的甜点方块分多层叠放(层与层错开半格)。被上层任何方块压住的方块变暗、不能点。
2. 点击一个未被压住的方块,它飞进底部的托盘(7 格),并自动插到同类方块旁边。
3. 托盘里凑满 3 个相同甜点,立即合成消除。
4. 清空棋盘上的所有方块 = 胜利;托盘 7 格占满且无法消除 = 失败。
5. 关卡由生成器保证有解:先确定方块位置并模拟一个“永远只拿露出方块”的移除顺序,再按这个顺序每 3 个分配同一种甜点。

## 道具(demo 每关各 1 次)
- 撤回:把最后放入托盘的方块退回原位。
- 移出:把托盘最左边的 3 个方块移到托盘上方的暂存行(最多 3 格),暂存行里的方块可以再点回托盘。
- 洗牌:打乱棋盘上剩余方块的甜点种类(保持仍然有解)。

## 评价与连击
- 不用道具通关 3 星,用 1 个 2 星,用 2 个及以上 1 星。
- 3 秒内连续消除记为连击,屏幕上弹出“棒!/太棒了!/完美!”。

## 甜点(10 种)
马卡龙、甜甜圈、纸杯蛋糕、草莓蛋糕、牛角包、冰淇淋甜筒、曲奇、布丁、棒棒糖、巧克力。

## 手感与动画(时长为初始值,按试玩调整)
- 入场:方块从上到下按层依次落下,每块 0.25s,层间间隔 0.08s,总时长 ≤1.2s。
- 点击:方块轻压缩放 0.95→1.0(0.08s),沿弧线飞入托盘 0.28s(ease-out),落位时轻弹。
- 托盘重排:其余方块滑动让位 0.15s。
- 三连消除:三块向中间靠拢并放大 1.15(0.12s)→ 合成闪光 + 星星粒子 → 消失(0.2s)。
- 新露出的方块:变暗层淡出 0.15s。
- 失败:托盘左右抖动 0.3s;胜利:彩带 + 星级依次亮起(间隔 0.18s)。

## 页面(1080×1920)
顶部:左上暂停圆钮;居中关卡牌“第 N 关”;右上金币胶囊;下方一条消除进度条(3 颗星标记)。
中部:叠层棋盘。下部:暂存行(3 格,平时隐藏)、托盘(7 格)。底部:三个道具圆钮(撤回 / 移出 / 洗牌),每个带红色数量角标与文字。
