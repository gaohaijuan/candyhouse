## 1. 为什么要做(定位)
- 金币目前只能买道具,赚了没处花。装修是长期、可见的金币去处。
- 成就感来源:**亲手选、亲手摆、亲手配色**,每一步都能立刻看到房子变漂亮;完成后有展示与奖励;收藏/成就记录长期进度。
- 参考同类做法(Homescapes / Royal Match 的“用星星装修”、Animal Crossing 的自由摆放与配色):我们取“轻量自由度”——摆放位固定、可选款式与颜色自由,避免完全自由摆放的操作负担。

## 2. 核心循环
过关得金币 → 进糖果屋 → 选一个空位(+)→ 商店抽屉里挑组件(按价格/解锁)→ 放上去(落位动画+星光+音效)→ 选中后换颜色/换款式 → 装修度 +N → 满一个房间:房间完成仪式+奖励 → 解锁下一个房间/屋外区域。

## 3. 内容结构
- **房屋分区**(按章节解锁,一章一区,和关卡地图章节对应):客厅 → 厨房/烘焙台 → 卧室 → 花园(屋外)→ 屋顶与外墙 → 甜品店门面。
- **每区 8–10 个摆放位**(固定锚点,等距 2.5D):大件(沙发、床、柜)、小件(台灯、摆件)、墙面(画、窗帘)、地面(地毯)、整体(墙纸、地板)。
- **每个摆放位 3 款可选**(价格递增:基础款 / 精致款 / 稀有款),每款 **6–8 种配色**(调色盘;稀有色可由成就解锁)。已买的款式可随时免费切换(鼓励尝试)。
- 装修度 = 已填摆放位数(换款式/颜色不加分,避免刷分);每区满分 = 摆放位数。

## 4. 让 DIY 有成就感的关键细节(实现时逐条落实)
1. **即时可见**:选款式时在场景里实时预览,确认才扣金币;换颜色实时着色(切图做成灰度底图+着色遮罩,或每色一张图,取决于美术)。
2. **落位仪式**:组件从天而降 + 轻微弹跳 + 星光粒子 + “叮”;装修度进度条增长;每满 25% 小庆祝。
3. **搭配加成**:同一区内同色系 ≥3 件 → “配色达人”小提示 + 少量金币(鼓励思考搭配,而不是随便放)。
4. **前后对比**:房间完成时播放“装修前 → 装修后”滑动对比,然后 H3 完成页 + 奖励。
5. **拍照/分享**:完成页可保存截图(带 Logo 水印位),以后接分享。
6. **随时回味**:主页背景显示玩家自己装修的房子(不是固定图),最有归属感。
7. **价格节奏**:按关卡金币产出算——普通玩家约每 3–5 关能买一件基础款;稀有款需攒 15–20 关;保证每次进屋都“刚好能买一件”。

## 5. 成就系统(先做框架,内容逐步加)
- **分类**:闯关(通关 N 关、三星 N 关、不用道具通过难关)、装修(完成第 N 个房间、收集 N 件组件、用满 8 种颜色)、收集(全部甜点图案见过)、日常(连续签到 N 天)。
- **分级**:每个成就 铜/银/金 三级,数字递增(如三星 10/30/50 关)。
- **奖励**:金币、道具、**专属稀有配色/稀有组件**(成就是稀有装饰的唯一来源 → 两套系统互相拉动)。
- **展示**:成就页(奖杯墙)+ 达成时顶部横幅;房子里可放“奖杯柜”组件展示金级成就。
- 数据:data/achievements.json(id、分类、等级阈值、奖励);profile 记录进度与已领取;所有统计在现有事件处累加(record_win、use_booster、purchase、checkin)。

## 6. 技术方案要点
- 场景:Control + 分层 TextureRect(背景房间 → 墙纸/地板 → 家具按 y 排序 → 前景)。锚点坐标写 data/house.json(区、摆放位、可选款式、价格、解锁条件)。
- 换色:优先“灰度底图 + shader 着色(保留高光)”,一张图出所有颜色;美术需按此要求切图(Codex 出图时说明)。
- 存档:profile.data.house = {zone: {slot: {item, color}}};装修度、已拥有列表。
- 测试:meta_tests 覆盖购买/切换/装修度/房间完成奖励/成就进度与领取。

## 7. 开发顺序(排在难度与当前版本之后)
1. 设计数据表(客厅 10 个摆放位 × 3 款 × 8 色)与价格表 → 用户确认。
2. Codex 按 H1/H2/H3 出切图:客厅底图、30 件组件灰度底图 + 着色遮罩、面板与按钮。
3. 写装修场景 + 商店抽屉 + 换色 + 存档 + 落位动画。
4. 完成仪式与奖励;主页显示自己的房子。
5. 成就框架 + 第一批 20 个成就。
6. 后续房间与成就内容按版本追加。
